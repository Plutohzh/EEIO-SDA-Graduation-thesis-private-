仓库内容：
（1）rawdata/：存放原始数据与中间数据，如国家统计局原始的投入产出表、依托《成本收益汇编》整理的数据等。
（2）tableconstruction/：存放编表过程中的相关数据与Python代码，如IO表工作簿、RAS法代码、合并代码等。其中，各年份IO表工作簿内设多个工作表（sheet），每次更新或迭代的版本都以工作表形式保存，读者可按工作表顺序追溯完整计算过程。
（3）calculation/：存放计算完全排放、生产层分解、排放影响力和感应度系数、SDA等的Python代码，以及最终的138部门EEIO表（不含公式）。
（4）README文档，给出了复现步骤与运行环境。
复现步骤：
（1）打开tableconstruction中各年份的投入产出表工作簿，按其工作表顺序执行操作如下：
在“细分自动平衡”工作表中输入数据来源表中计算得到的剥离系数，表格将通过公式自动计算实现表格平衡；
将数据来源表中的油菜种植部门投入结构输入油菜种植部门，得到“手动未平衡”工作表；
将中间流量矩阵及中间使用合计的行列目标分别导出，建议直接使用RAS文件夹中提供的带“input”后缀的工作簿，得到各年份后缀“balanced”的工作簿后，将其数据输入到原工作簿“RAS平衡”工作表。
按“完全平衡”工作表中提供的调整值及其方法、公式，对“RAS平衡”工作表的最终使用和最终投入进行调整。完成细分部门编表工作。
（2）将三年份细分的投入产出表整合到一个工作簿中，建议直接使用仓库提供的“通表”。运行合表程序的代码，得到统一部门的投入产出表。
（3）按程序要求准备价格指数表与平减用的投入产出表。建议直接使用带“平减用”后缀的表格。运行代码，并将数值输入到仓库提供的投入产出表模板中，以自动更新合计项。
（4）因数据使用协议，读者需自行下载CEEIO提供的相关数据，提取各年份的149部门二氧化碳与氧化亚氮的实物排放量，按部门映射关系与带“e”后缀的IO表中提供的必要说明与氮排放计算公式，整理出138部门的实物排放量向量，编入138部门投入产出表，得到EEIO表。
（5）将原模板整理为数值类型，提取代码所需的向量或矩阵到新工作表，或直接使用仓库提供的带“EEIOnum”后缀的表格，运行核算、SDA相关代码即可得到结果。
